## 1. Host 插件骨架（必须照这个形状）

```js
export const name = 'dsh-torso'
export const inject = ['webServer']          // 数组=必需依赖，没 webServer 就不激活

export function apply(ctx, config = {}) {
  // ctx.effect(fn, label) 注册的东西，返回的 disposer 由框架管理
  ctx.effect(() => ctx.webServer.register({
    kind: 'prefix',
    path: '/api/torso',
    handler: (req, res) => { /* 自行分发 */ },
  }), 'torso: api')
}
```

- 路由只注册一次（`kind:'prefix'` + `path:'/api/torso'`），handler 里用 `new URL(req.url, 'http://localhost')` 取 `pathname` 和 `searchParams`。重复注册同一个 `(kind,path)` 会抛错。
- 路径匹配用 `pathname.slice('/api/torso'.length)`，得到 `/ping`、`/task` 这样的后缀。
- 响应头一律 `content-type: application/json; charset=utf-8` + `cache-control: no-store`；文件路由例外。
- 本机单用户，不要做鉴权。
- 生成任务用内存 Map 存状态，进程重启即丢（可接受）。
- 所有异常都要捕获并返回 `{ok:false, error:'人类可读的原因'}`，不要让 handler 抛到 webServer（会 500 且没有原因）。
- **不要**写任何 Cordis 服务、不要 register 别的路由、不要动 profile。

## 2. 数据落盘

数据根目录（root）解析顺序：
1. `config.root`（patch 里没配，一般用不到）
2. `ctx.get('workingDirectory')?.defaultDirectory` + `\Torso`
3. `os.homedir() + '\.dsh-torso'`

root 下结构：

```
Torso\
  设置.json
  项目\<projectId>.json
  素材\<projectId>\<文件名>
```

- 首次访问时 `mkdir -p`（`fs.mkdirSync(dir,{recursive:true})`）。
- 写 JSON 用「写临时文件 + rename」，防写坏。
- `projectId` 形如 `p-k3f9a2-x7q1`（ASCII，`[a-z0-9-]`）。
- 资产文件名形如 `<shotId>-<slot>-<时间戳>.<png|jpg|mp4|webm>`，`slot ∈ first|last|video`。
- 项目里保存的资产路径是**相对 root 的路径**（`素材/<projectId>/xxx.png`），统一用 `/` 分隔。UI 通过 `/asset?p=` 取。

## 3. Host HTTP 接口

统一前缀 `/api/torso`。成功 `{"ok":true, ...}`；失败 HTTP 200 + `{"ok":false,"error":"..."}`（不要用 4xx，客户端只看 ok）。

| 方法 路径 | 请求 | 返回 |
| --- | --- | --- |
| `GET /ping` | — | `{ok:true,name:'dsh-torso',version:'0.1.0',root}` |
| `GET /state?projectId=` | — | `{ok:true,projects:[…],settings,project,root}` 见下 |
| `GET /project?id=` | — | `{ok:true,project}` |
| `POST /project/create` | `{title?}` | `{ok:true,project}` |
| `POST /project/save` | `{project}` | `{ok:true,updatedAt}`（服务端重设 `updatedAt=Date.now()` 后再存） |
| `POST /project/delete` | `{id}` | `{ok:true}` |
| `GET /settings` | — | `{ok:true,settings}` |
| `POST /settings` | `{settings}` | `{ok:true}` |
| `POST /asset/upload` | `{projectId,shotId,slot,name,dataUrl}` | `{ok:true,asset,url}` |
| `GET /asset?p=<相对路径>` | — | 文件本体，按扩展名给 content-type；mp4 支持 `Range` |
| `POST /generate/image` | `{channelId,projectId,shotId,slot,prompt,size?}` | `{ok:true,taskId}` |
| `POST /generate/video` | `{channelId,projectId,shotId,prompt,firstAsset?,lastAsset?,duration?,ratio?}` | `{ok:true,taskId}` |
| `GET /task?id=` | — | `{ok:true,task}` |

`/state` 返回：

```jsonc
{
  "ok": true,
  "root": "D:\\DESKTOP\\DEEPSEEK专用\\Torso",
  "settings": { … },
  "projects": [   // 按 updatedAt 倒序
    { "id": "p-…", "title": "…", "updatedAt": 1762123456789, "shotCount": 12,
      "cover": "素材/p-…/s-…-first-…png" }   // 第一张有图的首帧，可空
  ],
  "project": { …当前项目…… }   // projectId 给了且存在才有，否则 null
}
```

`/task` 返回：

```jsonc
{ "ok": true,
  "task": {
    "id": "t-…", "kind": "image"|"video", "status": "running"|"done"|"error",
    "progress": "已提交，等待中",        // 给 UI 显示的一句话
    "startedAt": 1762123456789,
    "result": { "asset": "素材/…", "url": "/api/torso/asset?p=…" },  // done 时
    "error": ""                                                    // error 时
  } }
```

任务记录至少保留 1 小时；每次请求顺手清掉超时的。

## 4. 图像生成（OpenAI 兼容）

`POST {baseUrl}/images/generations`，headers `authorization: Bearer <apiKey>`（apiKey 为空则不带头）、`content-type: application/json`。

请求体：`{ model, prompt, n: 1, size, response_format: "b64_json" }`
- baseUrl 已以 `/images/generations` 结尾就直接用，否则拼 `/images/generations`（注意去掉结尾 `/`）。
- 有些网关不认 `response_format` → 若返回 4xx 且报错提到 `response_format`，去掉它重试一次。
- 取 `data[0].b64_json` 解码保存；没有就 `data[0].url` 再 `fetch` 下载。两者都没有 → 报错并带上响应前 300 字。

## 5. 视频生成（异步任务）

三个真适配器 + 一个通用适配器。统一内部接口：

```js
createVideoTask({channel, prompt, firstFrameDataUrl, lastFrameDataUrl, duration, ratio}) → {remoteTaskId}
queryVideoTask({channel, remoteTaskId}) → {status:'running'|'done'|'error', videoUrl?, error?}
```

`firstFrameDataUrl` 是 `data:image/png;base64,...` 形式的完整 data URL（从资产文件读出来现做）。

### 5.1 ark（火山方舟 Seedance）

- base 默认 `https://ark.cn-beijing.volces.com/api/v3`
- 创建：`POST {base}/contents/generations/tasks`
  ```json
  { "model": "<model>",
    "content": [
      {"type":"text","text":"<prompt>"},
      {"type":"image_url","image_url":{"url":"<data url>"},"role":"first_frame"},
      {"type":"image_url","image_url":{"url":"<data url>"},"role":"last_frame"}
    ],
    "ratio": "<ratio 或 adaptive>", "duration": 5, "resolution": "720p" }
  ```
  `last_frame` 那条仅在尾帧存在时加。返回 `{id}`。
- 查询：`GET {base}/contents/generations/tasks/{id}` → `{status, content:{video_url}}`；
  `status ∈ queued|running|succeeded|failed|expired|cancelled`。

### 5.2 kling（可灵，JWT 鉴权）

- base 默认 `https://api-beijing.klingai.com`
- 鉴权：`Authorization: Bearer <JWT>`，HS256，payload `{iss: apiKey(accessKey), exp: now+1800, nbf: now-5}`；**设置里的 apiKey 允许写成 `ak:sk` 两段**（用冒号分隔，分别当 accessKey/secretKey）；只有一段时当作 accessKey，secretKey 从 `channel.custom.secretKey` 取（若都没有就报错说明）。
- 创建：`POST {base}/v1/videos/image2video`
  ```json
  { "model_name": "<model>", "image": "<data url>", "image_tail": "<可选 data url>",
    "prompt": "<prompt>", "negative_prompt": "", "cfg_scale": 0.5,
    "mode": "std", "duration": "5", "aspect_ratio": "9:16" }
  ```
  返回 `{code:0, data:{task_id}}`；`code !== 0` 抛错带 message。
- 查询：`GET {base}/v1/videos/image2video/{task_id}` → `{data:{task_status, task_result:{videos:[{url}]}}}`；
  `task_status ∈ submitted|processing|succeed|failed`。

### 5.3 wan（阿里云百炼 通义万相）

- base 默认 `https://dashscope.aliyuncs.com`
- 创建：`POST {base}/api/v1/services/aigc/video-generation/video-synthesis`，额外头 `X-DashScope-Async: enable`
  ```json
  { "model": "<model>", "input": {"prompt": "...", "img_url": "<图片公网 URL>"},
    "parameters": {"resolution": "720P", "duration": 5} }
  ```
  注意：`img_url` 只认公网 URL，data URL 不行 —— 遇到本地资产直接报错提示用户换 ark/kling 或自建图床。
  返回 `{output:{task_id}}`。
- 查询：`GET {base}/api/v1/tasks/{task_id}` → `{output:{task_status, video_url}}`；
  `task_status ∈ PENDING|RUNNING|SUCCEEDED|FAILED|CANCELED`。

### 5.4 custom（通用模板适配器）

用 `channel.custom` 里的模板：
- `createBody` 是 JSON 字符串，替换占位符 `{{prompt}}`、`{{firstFrame}}`、`{{lastFrame}}`、`{{duration}}`、`{{ratio}}`、`{{model}}`（字符串替换，注意 JSON 转义：先 `JSON.stringify(value)` 再去掉首尾引号再替换，避免 prompt 里的引号破坏 JSON）。
- 创建 URL 里的 `{{model}}`/`{{apiKey}}` 同样替换。
- 任务 id 按 `taskIdPath`（点分路径，如 `data.task_id`）从响应里取。
- 查询 URL 里的 `{{taskId}}` 替换；状态按 `statusPath` 取，和 `successValues`/`failValues`（逗号分隔，忽略大小写）比较。
- 视频地址按 `videoPath`（点分路径）取，也可以写数组下标 `data.videos.0.url`。

### 5.5 任务执行

- `/generate/image`、`/generate/video` **立刻返回 taskId**，真正的工作在后台跑（不要 await 完再返回）。
- 服务端自己轮询视频供应商（间隔 5 秒，上限 20 分钟），成功后下载视频到 `素材/<projectId>/<shotId>-video-<ts>.mp4`，任务置 done 并回填 `result.asset`。
- 图片任务生成完直接存盘。
- 服务端**不要**改项目 JSON 里的 shot（客户端会自己保存结果，避免双写冲突）。

## 6. Client 半边（client/client.js）

必须用宿主模块表，不要装 React、不要 JSX（用 `React.createElement`）：

```js
window.__ModuleLoader__.load({
  id: 'dsh-torso',              // 必须等于包名
  factory: (require) => {
    const React = require('react')
    const h = React.createElement
    // …组件…
    const exports = { name: 'dsh-torso', inject: ['slots'], apply(ctx) { … } }
    return exports
  },
})
```

`apply(ctx)` 里注册两个位置：

```js
ctx.slots.inject('sidebar.panellist', () =>
  ctx.slots.register(
    { name: 'sidebar.panellist', id: 'torso', order: 40, label: 'Torso' },
    SidebarIcon,          // props: { size:number, active:boolean }，只画图标
  ))
ctx.slots.inject('main', () =>
  ctx.slots.register(
    { name: 'main', key: 'torso' },   // main 是 keyed slot，用 key
    Studio,                                    // 主面板组件，铺满中央区域
  ))
```

- 侧边栏图标组件只画一个 SVG（`width/height = size ?? 20`，`stroke="currentColor"`）。
- 样式：apply 里 `ctx.effect(() => { const el=document.createElement('style'); el.textContent=CSS; document.head.appendChild(el); return () => el.remove() }, 'torso: styles')`。
- 主题颜色一律用宿主 token，带兜底：`var(--dsw-alias-bg-base,#fff)`、`--dsw-alias-bg-layer-1/2/3`、`--dsw-alias-border-l1/l2`、`--dsw-alias-label-primary/secondary/tertiary/quaternary`、`--dsw-alias-brand-primary`、`--dsw-alias-state-success-primary`、`--dsw-alias-state-danger-primary`、`--dsw-alias-state-warn-primary`、`--dsw-alias-bg-hover`、`--dsw-font-family`。
- 数据访问：`fetch('/api/torso/…')`（同源，见 §3）。
- 不要读写别的插件的 DOM，不要往 body 里塞第二个应用（主面板是普通 React 组件，铺满父容器即可）。
- 面板根元素 `height:100%; display:flex; flex-direction:column; overflow:hidden`。

### 6.1 界面结构（硬要求）

```
┌ 顶栏 44px ───────────────────────────────────────────────┐
│ Torso   [项目下拉▾] [＋新项目]      ● 已保存  [样式/渠道⚙] │
├ 主体 flex:1（画布 + 右侧检查器） ─────────────────────────┤
│  画布（无限，可缩放平移，镜头卡片可拖）        │ 检查器 380px │
├ 底栏 40px ───────────────────────────────────────────────┤
│ [＋ 添加镜头]                        12 镜 · 总时长 1:02  │
└──────────────────────────────────────────────────────────┘
```

**画布**：点阵背景；滚轮以光标为中心缩放（0.2~2.5）；空白处拖动平移；卡片拖动改位置并存盘；点卡片选中（描边高亮），弹右侧检查器；右上角有「适应画面 / 100%」小控件。

**镜头卡片**（宽 300）：头部 镜号 + 景别·运镜 + 时长；中间两个 9:16 缩略图（首帧/尾帧，宽各 128，无图显示虚线占位「首帧/尾帧」+ 生成按钮）；下面台词两行（截断）；右下角状态点/视频标记（有视频显示 ▶ 角标）。

**检查器**：只显示选中镜头。字段：镜号、景别（下拉：大远景/远景/全景/中景/中近景/近景/特写/大特写）、运镜（下拉：固定/推/拉/摇/移/跟/升降/环绕）、时长（数字 1~15）、台词、画面动作、备注；「首帧」区：提示词 textarea + [生成] + [导入图片] + 状态/重试；「尾帧」区同上；「视频」区：视频提示词 + 视频渠道下拉 + [生成视频] + 进度 + `<video controls>` 预览 + [导入视频]；底部 [删除镜头]。

**渠道设置**（模态框）：图像渠道列表（名称/baseUrl/apiKey/model/尺寸，可增删，选默认）；视频渠道列表（名称/供应商下拉 ark·kling·wan·custom/baseUrl/apiKey/model/ratio/resolution/duration/audio，选默认，custom 展开模板字段），保存到 `/settings`。

**其它交互**：无渠道时点生成 → 友好提示「先去设置里加一个图像渠道」；生成中显示转圈与轮询（2 秒一次，最多 10 分钟）；任何接口错误用顶部 toast 显示 `error` 原文；保存防抖 800ms，顶栏显示 已保存/保存中/保存失败。

## 7. 验收

1. `node --check client/client.js`（宿主加载前语法必须过）。
2. 安装后侧边栏出现图标，点开是完整工作台，不白屏、不报 "slot entry crashed"。
3. 新建项目 → 加镜头 → 写首帧提示词 → 生成（没渠道时是友好提示）→ 保存后刷新还在。
4. 手改 `项目/*.json` 后点「刷新」能从服务端读到新数据。
